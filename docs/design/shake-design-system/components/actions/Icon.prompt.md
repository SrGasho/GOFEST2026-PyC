One-line: a Material Symbols Rounded glyph, sized and filled via the variable font axes.

```jsx
<Icon name="person_search" size={24}/>
<Icon name="home" fill /> {/* active nav destination */}
```

Fill is state, not decoration: outlined for inactive, filled for the selected destination or a "confirmed" record. Sizes 20 / 24 / 40 / 48 only.
