One-line: the single screen-level action; in Shake that is almost always "Report a person".

```jsx
<FAB icon="person_add" label="Report someone"/>
<FAB icon="my_location" size="small" color="surface"/>
```

Sits 16dp from the right edge and 16dp above the navigation bar. `color="emergency"` is reserved for the SOS action and never appears alongside another FAB.
