One-line: the M3 common button — one filled button per screen, everything else steps down in emphasis.

```jsx
<Button variant="filled" icon="check_circle" size="lg" fullWidth>I\u2019m safe</Button>
<Button variant="outlined">Not now</Button>
```

Fully rounded (shape-full). Height 40dp default; 56dp `lg` only for the single safety action on the check-in screen. `danger` is red-filled and always confirmed by a Dialog.
