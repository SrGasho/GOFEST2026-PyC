One-line: a blocking decision — used in Shake for marking a person found, or clearing a report.

```jsx
<Dialog icon="warning" headline="Mark Mei as found safe?" supporting="Everyone following this record is notified immediately." actions={<><Button variant="text">Cancel</Button><Button>Confirm</Button></>}/>
```

Positions absolutely inside its nearest positioned ancestor so it scrims a phone frame, not the whole page. Confirm action goes last (rightmost). Never more than two actions.
