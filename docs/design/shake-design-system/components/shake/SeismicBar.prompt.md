One-line: the always-on banner naming the active event, pinned directly under the top app bar.

```jsx
<SeismicBar magnitude="6.4" place="12 km NE of Nagoya" time="Today 04:12 JST" level={5}/>
```

One per screen, never dismissible while an event is active. The ramp is the seismic tokens, not the status tokens — intensity is about the ground, not about a person.
