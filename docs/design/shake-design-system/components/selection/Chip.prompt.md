One-line: compact, always-tappable — filters above a registry list, or an entered search facet.

```jsx
<Chip type="filter" label="Missing" selected onClick={t}/>
<Chip type="input" label="Sakae 3-chome" onRemove={r}/>
```

Chips are 8dp radius, never pill — that is what separates them from Buttons. Chip rows scroll horizontally and never wrap on a phone.
